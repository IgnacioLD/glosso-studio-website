Glosso Studio is built using cutting-edge technologies for cross-platform and machine learning on mobile.

- **Framework:** [Kotlin Multiplatform (KMP)](https://kotlinlang.org/docs/multiplatform.html)
- **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Android)
- **Dependency Injection:** [Koin](https://insert-koin.io/)
- **Database:** Room (Android)
- **Networking:** [Ktor Client](https://ktor.io/)
- **Machine Learning:** [ONNX Runtime](https://onnxruntime.ai/) for Android
- **Phonetic Model:** [Allosaurus](https://github.com/xuechengliu/allosaurus) `eng2102`
- **Text-to-Speech:** Qwen3-TTS
- **Serialization:** Kotlinx Serialization
