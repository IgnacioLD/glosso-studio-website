Glosso Studio is an open-source project and is available through the following methods:

### Direct Download

You can find the latest APKs in the **Releases** section of the GitLab repository.

<a class="btn btn-pri" href="https://gitlab.com/shirobyte421/glosso-studio/-/releases" target="_blank">GitLab Releases</a>

### F-Droid

Glosso Studio is designed for compatibility with [F-Droid](https://f-droid.org/). Look for it in the official store or add our custom repository.

### Source Code

If you prefer to build it yourself, the source code is available on GitLab.

```bash
git clone git@gitlab.com:shirobyte421/glosso-studio.git
cd glosso-studio
git lfs install
git lfs pull
```
