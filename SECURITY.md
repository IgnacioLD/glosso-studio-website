# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this website or any of Glosso Studio's projects, please report it privately.

**Do not report security vulnerabilities through public GitHub issues.**

Instead, reach out directly to the project maintainer via the contact information available on the [GitHub profile](https://github.com/IgnacioLD).

You should receive a response within 48 hours. If you don't, follow up to ensure the message was received.

## Scope

- The Glosso Studio website source code
- Content and configuration files in this repository

For vulnerabilities in Glosso Studio apps (pronunciation trainer, TransitOS), report them in the respective project repositories.
