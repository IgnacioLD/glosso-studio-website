# Contributing

Thanks for your interest in contributing to the Glosso Studio website.

## Issues

- Use the [issue templates](.github/ISSUE_TEMPLATE/) for bug reports and feature requests
- Search existing issues before opening a new one
- Provide clear reproduction steps for bugs

## Pull Requests

1. Fork the repo and create a branch from `main`
2. Make your changes and test locally with `hugo server`
3. Ensure the site builds without errors: `hugo --minify`
4. Open a PR with a clear description of what you changed and why

## Code style

- Keep it simple — this is a static site
- Follow the existing HTML/CSS patterns in `layouts/` and `assets/`
- Markdown content goes in `content/`
